# Density tokens

Compact/comfortable/spacious. Density changes spacing, type rhythm and secondary-action
visibility; never hides a primary action or changes IA.

| Token ID | Mode | Space scale | Type scale | Secondary actions |
|---|---|---|---|---|
| `TOK-DENSITY-COMPACT` | compact | 0.75 | 0.92 | in overflow |
| `TOK-DENSITY-COMFORTABLE` | comfortable | 1.0 | 1.0 | visible |
| `TOK-DENSITY-SPACIOUS` | spacious | 1.5 | 1.08 | visible, fewer |
